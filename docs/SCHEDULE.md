# 自動更新の時刻（全8場）

2026-09-03 に全ワークフローの cron を **2時間前倒し**（UTC 22:xx → 20:xx ＝ JST 7時台 → 5時台）。

## 理由

GitHub Actions の定時実行は混雑で大きく遅れる。8/27〜9/2 の実測では、
JST 7時台に予約した各場ビルドが実際にページへ反映されたのは **8:46〜15:20**。
8/28 は 15 時（1R が終わったあと）、8/27・8/29 も 12 時台だった。

出走表（Bファイル）・前日結果（Kファイル）・前日の確定オッズはすべて前夜のうちに公開されているので、
5時に動かしても取れないものはない。3時間遅れても 8 時には間に合う。
