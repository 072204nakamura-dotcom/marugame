## 1. 最重要結論：若松は「番組の組み方」と「風・波」で崩れる水面

場全体では中立（+1.3pt）。日程（初日・最終日）・季節・時間帯では崩れない。崩れは次の3つに集中する。

1. **3R格差戦**（番組）：3Rは「B級の1号艇の外にA級を置く」番組が多い（1号艇B級83%・最強艇が5/6号艇の日が51%）。
2. **風5m以上・波5cm以上**（気象）：B級1号艇だけが飛ぶ。A級1号艇は効かない。
3. **選手の型**：1号艇スロー遅れ●・2号艇壁弱●（全国表）が若松でも再現。

1号艇の相対地力（出走表内の勝率順位）は大村と同じく効く（勝率1位 イン76%・+10.7pt／4位以下 −5.9pt）が、**崩れ側は3Rに集中**していて、3R以外の格差は有意でない（§3）。

## 4. スコアリング設計（アプリ実装）

判定順序が仕様の一部：**①進入固定 → ②レース名（特選系） → ③3R格差戦 → ④1号艇勝率最上位 → ⑤選手の型**。

| 項目 | 点 | 条件 |
|---|---|---|
| 進入固定 | 鉄板フラグ（見送り） | Bファイル見出しに「進入固定」、またはレース名に「進入固定」 |
| 準優勝戦・予選特選・特別選抜・ドリーム・優勝戦 | 鉄板寄りフラグ（加点なし） | NFKC後の部分一致「準優」（「準優進出」は除く）「予選特選」「特別選抜」「ドリー」「優勝」 |
| **3R格差戦** | **+2** | 3R かつ 1号艇B級 かつ 格差≤−1.5 |
| 1号艇 勝率最上位 | −1 | 格差≥0（同率含む） |
| **1号艇 スロー遅れ●** | **+1** | 採用スローST>0.18（当地10走以上は当地、なければ全国） |
| **2号艇 壁弱●** | **+1** | 全国壁表の下位10%（≤−13.0）。食う型／素通し型で買い目分岐 |
| 直前：風5m+ or 波5cm+ × 1号艇B級 | （+1で読む） | **自動加点しない**。カードの方針文とバナーで表示 |
| スロー巧者・壁強・残す/飛ぶ・モーター・潮・風向 | 0 | 表示のみ |

型（③④）は特選系・進入固定には加点しない。

ラベル：合計 ≥2.0「穴の巣」／≥1.0「崩れゾーン」／≤−1.0「鉄板寄り」／それ以外「中立」。進入固定は点数に関係なく「鉄板・見送り」、特選系は「鉄板寄り」。
（大村より閾値が1段低いのは、若松は+1の時点でイン36%まで落ちるため。§2⑦）

## 5. 買い目フォーム（若松版・中穴路線）

崩れゾーン以上の338Rの実績：頭 1号艇110・2号艇74・3号艇63・4号艇41・5号艇28・6号艇22。1号艇は2〜3着に36%。3連複の組は 1-2-3(47)・1-2-5(33)・1-2-4(32)・1-3-4(28)・2-3-4(20)。人気帯 1〜5位23%／6〜12位25%／13〜24位20%／25〜50位21%／51位以降11%。

- **崩れ判定（スコア≥1）・無印**：本線 **2-1-全・3-1-全（8点）＋ 2-3-全・3-2-全（8点）**。3連複派は **1-2-3・1-2-4・1-2-5・1-3-4**（崩れ時の41%）。
- **2号艇 壁弱●・食う型**：2-1-全・2-3-全（2アタマ）。
- **2号艇 壁弱●・素通し型**：3-1-全・4-1-全・3-4-全（2号艇は頭から外す）。
- **1号艇 飛ぶ型**：1を外して 2-3-全・3-2-全＋4-2-3・4-3-2。
- **鉄板寄り・中立**：1頭固定・2着を4〜6号艇（1-4-全・1-5-全・1-6-2/3）。若松のイン逃げ決着の50%が15倍以上、そのうち57%は2着が4〜6号艇。
- **鉄板・見送り（5R・特選系）**：見送り。
- 共通：**3連単51番人気以降（目安170倍超）は買わない**。

**EVについての注意（重要）**：崩れゾーン以上で16点（2-1/3-1/2-3/3-2-全）を均等買いした場合の回収率は115%（前半120%・後半110%）だが、**95%信頼区間は73〜168%**で、**51番人気以降の的中を除くと59%（＝全120点買いのベースライン59.5%と同じ）**。つまりプラスは全部「買わない大穴」から来ている。中穴路線では、このフォームに価格の優位は確認できていない。EVの判断はオッズ蓄積後（§7）。
